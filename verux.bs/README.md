# Verux BS scaffold

This folder is an in-repository scaffold copied from the tracked Verux APB client files. It excludes the authoritative `license-server`, Git metadata, and build output. The copied APB implementation is a reference baseline; it has not been adapted, built, or cleared to run against Blood Strike.

The APB interface style is retained as the UI reference. The APB feature set and engine assumptions still need to be removed or replaced according to the proposal in [FEATURE_PROPOSAL.md](FEATURE_PROPOSAL.md). No BS offsets or process memory have been inspected.
